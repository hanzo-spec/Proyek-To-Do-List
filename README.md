# 📝 Interactive To-Do List App

Aplikasi pengelola daftar tugas (*To-Do List*) berbasis web yang interaktif, dirancang untuk membantu pengguna mencatat dan mengelola aktivitas harian dengan efisien.

## 🚀 Fitur Utama
* **Tambah Tugas Baru:** Menambahkan daftar pekerjaan secara fleksibel.
* **Hapus Tugas:** Menghapus tugas yang sudah selesai atau tidak diperlukan.
* **Validasi Input:** Mencegah penambahan tugas kosong.
* **Desain Responsif:** Tampilan yang bersih dan nyaman digunakan di berbagai ukuran layar.

## 🛠️ Teknologi yang Digunakan
* **HTML5:** Membuat struktur dasar halaman web.
* **CSS3:** Memberikan gaya tampilan, warna, dan tata letak (*layout*).
* **JavaScript (Vanilla JS):** Mengelola interaktivitas manipulasi DOM (*Document Object Model*) untuk penambahan dan penghapusan item secara dinamis.
